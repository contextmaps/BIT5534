Learning Objectives

By the end of this part, students will be able to:

  1. Build a stack for a category target from the saved probabilities of four base models, on a fold column the file supplies.
  2. Read a logistic regression meta-model's coefficients and logworths as the weight it gives each base model.
  3. Compare a logistic regression meta-model with a support vector machine meta-model through their test confusion tables.
  4. Explain why a missed readmission and a false alarm do not cost the same, and let that difference decide between two meta-models.
  5. Recognize an overfitted network from its train and validation figures, and say what a stack of networks gains over its best member.

Part 2 is about the stacking from the week 8 lectures, on one file. Case one stacks four model families. Case two stacks four neural networks.

The file is readmissions.csv from Wrenfield Regional Hospital, a hospital made up for this homework. Each row is one patient discharged after a stay. Readmitted is Yes when the patient came back as an inpatient within 30 days, and No otherwise. A transitions nurse at Wrenfield can call a limited number of patients in the week after discharge, and the hospital wants a model that tells the nurse whom to call.

Two kinds of error matter here, and they are not the same size. A false negative is a patient the model calls No who is readmitted, a patient the nurse never called. A false positive is a patient the model calls Yes who would have been fine, a call the nurse did not need to make. Neither case asks for a dollar figure. Both cases ask you to say which error is worse for Wrenfield, and to let that judgment decide between two meta-models.

The file carries its own Fold column. Every row is marked validation_1 to validation_5 or test, five folds of 210 rows and 450 test rows. Use that column in every fit. Each base model then saves, for every row, a probability from the fold model that did not see the row, and every test row takes the average of the five fold models.

Your regression, tree and support vector machine figures are the same on every machine, and the checks on this page give them to the third decimal. Your network figures may differ from a classmate's, because a network's random start plays out differently from one machine to another. Your meta-models are fitted on your own saved columns, so their figures may differ too. The rubric reads your figures for consistency with each other, so report what your tools show.

Step 1, logistic regression. Open readmissions.csv in reg_explorer.py, set the panel and fit. Read the test row and the test confusion table on the Fit tab. Press Save probabilities and keep the name the tool offers, readmissions_stack.csv.

Step 2, the tree. Open readmissions_stack.csv in tree_explorer.py, set the panel, leave 4 splits and a smallest leaf of 5, and fit. The column REG prob Yes starts unselected, and it stays that way. Save probabilities over readmissions_stack.csv.

Step 3, the network. Open readmissions_stack.csv in nn_explorer.py, set the panel, leave 3 tanh in the first layer, 1 start and seed 123, and fit. Save probabilities over the same file.

Step 4, the support vector machine. Open readmissions_stack.csv in svm_explorer.py, set the panel, choose RBF, C 1 and an empty Gamma, and fit. Save probabilities over the same file.

Check three things. The Validation column tab lists five folds of 210 rows and 450 test rows. Logistic regression gives average validation misclassification 0.174 and test 0.216, with 64 readmitted patients predicted No on the test rows. The support vector machine gives average validation 0.176 and test 0.187, with 59 readmitted patients predicted No.

Now the two meta-models, both on the four saved columns alone.

Case one stacked four families. Case two stacks four networks of different shapes on the same file, the same nine inputs and the same Fold column. A stack of networks asks a different question. Every member is the same kind of model, so the meta-model shows how much one shape adds to another, and whether a network that overfits still adds anything.

Open readmissions.csv, the original file and not the case one stack, in nn_explorer.py. Set the panel as in case one. Set Number of starts to 10 and leave the seed at 123 for all four networks. Fit them in this order, setting the counts in the tanh column. First 6 tanh in the first layer and 0 in the second. Then 24 tanh in the first layer and 0 in the second. Then 3 tanh in each layer. Last, 12 tanh in each layer.

Save probabilities after each fit. On the first save, type the name readmissions_nets_stack.csv, so case one's file is left alone, and save over that name after the other three.
