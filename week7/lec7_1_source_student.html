Learning Objectives

By the end of this lecture, students will be able to:

  1. Write what one hidden neuron computes and what the output neuron computes, and sketch the four activation functions.
  2. Count the parameters of a network with one or two hidden layers.
  3. Explain why a network is fitted from several random starts and how a seed makes a fit repeat.
  4. Make a validation column for a holdout or for k folds, and say which rows fit the model and which rows judge it.
  5. Build a neural network tool from a specification whose four parts carry forward by different distances.
  6. Read train and validation R squared side by side and defend a network size.
Section 1 of 5
INTRODUCTION
📋 Note for Students

Last Thursday ended on a question. Every R squared on the split history was measured on the same hundred students the tree was grown from, so how would we know whether the splits hold for next year's freshmen? Today answers that question, and it does so with a new model.

The file is 804 used cars and their asking prices. For the first fifteen minutes you watch: the neural network written out, its parameters counted, and how it is fitted.

804 used cars. For each car the file holds its asking price, its mileage, its make and model, its trim and body type, its engine's cylinders and size in liters, its number of doors, and whether it has cruise control, a premium sound system and leather seats.

Logistic regression took a weighted sum of the inputs plus an intercept and passed it through one curve. A neuron does exactly that. A neural network is many neurons, arranged in layers.

The activation is what makes a network more than a regression. Python offers four.

💬 Discussion

Before the size card:

  • A network built only from identity neurons, in any number of layers. Which model is that?
  • Count the parameters in the figure. How many weights and biases does the network hold?

The size of a network is its number of parameters. Count them for the figure first: each hidden neuron holds four weights and a bias, and the output neuron holds two weights and a bias.

Fitting means choosing every parameter at once to make the mean squared error on the train rows as small as possible. With thirteen parameters the error is a surface in thirteen dimensions, and the curves give it many valleys. The optimizer starts from small random weights and walks downhill, so a different start can end in a different valley. A seed fixes the random starting weights, and the same seed gives the same fit.

The same counting describes the networks behind image recognition, speech and the chat assistants. The networks behind them have many layers and billions of parameters, counted with the same formula.

Section 2 of 5
DEMONSTRATION

A validation column gives every row a role. Train rows fit the network. Validation rows judge it, and the network sees none of them while it fits.

A holdout marks a share of the rows validation and the rest train. Five folds mark every row validation_1 to validation_5, and the model is fitted five times, each time on the rows outside one fold and judged on that fold.

Now the network on the projector, with one third held out and seed 123. One identity neuron first, then three, ten and forty tanh neurons.

Two more settings decide the fit. The standardize box rescales every input with the mean and standard deviation of the train rows. Clear it and three tanh neurons fall to an R squared of 0.000, because mileage runs into the tens of thousands and every tanh neuron flattens at one.

The number of starts fits the network from that many random starting points and keeps the start with the smallest validation mean squared error. A seed repeats a fit exactly on one machine. Your own machine may print other digits than the projector for the larger networks, because small differences between library versions grow over a thousand steps of the optimizer, and the pattern stays the same.

💬 Discussion

While it runs:

  • Train R squared rises as the network grows. What does each added neuron give the optimizer to work with?
  • Forty neurons predict a Cadillac at minus 19,664 dollars. Which rows would have told you, and which rows could not?
  • Three tanh neurons scored below two. Is that the size of the network or the start it was given?
