Neural Network Settings and Overfitting
Duration: 75 minutes · Platform: Hokie AI · Submission: Thread exported as a .zip and uploaded to Canvas before leaving class · Lecture Mode: consolidation
Learning Objectives

By the end of this lecture, students will be able to:

  1. Run a neural network experiment that changes one setting at a time and read train and validation results side by side.
  2. Recognize overfitting from computed evidence, a setting where train R squared rises while validation R squared falls.
  3. Explain why a network is fitted from many random starts, and what the kept start does and does not guarantee.
  4. Compare a one third holdout with five folds by how far each figure moves when the validation column is drawn again.
  5. Fit a network to a category target and read its confusion table.
  6. Explain what a neural network cannot report about its inputs, and what the choice of input columns did that no setting could.
  7. Question an AI assistant one step at a time, building each question on the last answer and checking answers against computed numbers.
Section 1 of 5
INTRODUCTION
📋 Note for Students

On Tuesday you watched three networks fitted to the same 804 cars. The smallest could not follow the prices, the middle network did well on both the train rows and the validation rows, and the largest did best on the train rows and worst on the validation rows. Today names what the largest network did, and shows you how to find the settings that suit a dataset.

You watch the software today. Your own work is a conversation with Hokie AI in section 3 and the reflection in section 5.

On Tuesday three networks were fitted to the same validation column, each with ten starts. The figure shows what the page's own run of the same three networks gives.

Every price in the file is a pattern plus noise. The pattern is what mileage, engine size and equipment say about the price. The noise is everything else, the dealer, the day, the condition of one car.

A network with enough parameters can fit the noise of the train rows as well as the pattern. The validation rows carry different noise, so the validation error rises while the train error keeps falling. The network has overfit the train rows. A network too small to follow the pattern is underfitting, and both R squared values stay low.

Fitting starts from random weights and walks uphill on a surface with as many dimensions as the network has parameters. Picture a mountain range in fog. Each start drops a climber at a random spot, and the climber walks up until no step goes higher, then reports the height of the summit where the climber stopped. More starts means more climbers, and the tool keeps the highest summit any climber reported.

A regression reports one coefficient per input, and the regression tree of week 6 reported each column's contribution to the tree's splits. A network reports neither. Ten tanh neurons on six inputs hold 81 parameters, and none of the 81 parameters says what an extra 10,000 miles does to the price. The network can predict well and still tell you nothing about how each column relates to the target.

💬 Discussion

Before the software:

  • Thirty climbers reported thirty heights. What does the kept height promise about the next car, and what does the kept height not promise?
  • A manager asks how much leather seats add to the price. What can a network tell the manager?
Section 2 of 5
DEMONSTRATION

The software runs on the projector. Every experiment keeps one validation column and changes one setting, so a difference in the results belongs to that setting.

The grid below holds every setting the page tested, each fitted with ten starts on five different validation columns. A line runs from the lowest validation R squared to the highest, the filled dot is the validation average and the open dot is the train average.

Read a setting by its range. Results move with the column and with the starts, so two settings differ only when their ranges barely overlap.

A holdout judges the network on one third of the rows, so the figure depends on which third. Five folds give every row one turn in validation and average the five verdicts. The figure below draws the validation column five times and fits the same network on each column.

DISCUSSION

The same network can predict a category. MedPrice is 1 when a car's price is above the median of 18,025 dollars and 0 when the price is at or below the median, 402 cars each way. The target becomes a category and Price comes out of the inputs, because MedPrice is built from Price.

For a category target the Fit tab reports accuracy, the share of rows classified correctly, and a confusion table, with the actual class down the side and the predicted class across the top.

Every network on this page used six inputs. The file holds five more columns, Make, Model, Trim, Type and Cylinder, and the last fit adds all of them.
