Section 1 of 5
INTRODUCTION
📋 Note for Students

Last week a network with enough neurons fitted the train rows almost perfectly and failed on the validation rows. Today brings a second model with that much capacity, the support vector machine, and the validation column comes with it.

For the first fifteen minutes you watch: a line between two classes, the widest margin around the line, the rows that decide it, and a kernel that bends it.

The first file is 64 rows with two inputs, x1 and x2, and a class y. Many lines separate the two classes. A support vector machine picks the line with the widest margin, the widest empty band between the classes.

Write the line as w1·x1 + w2·x2 + b = 0. The vector w = (w1, w2) is perpendicular to the line, w.x + b is positive on one side and negative on the other, and the class is recoded to y = +1 and y = -1.

Scale w and b so that the rows closest to the line sit exactly at w.x + b = +1 and w.x + b = -1. The distance from the line to those rows is 1 / ||w||, so the margin is 2 / ||w||. Maximizing the margin is minimizing ||w||², with every row on its own side of its dashed line. The result is the hard margin support vector machine.

Real classes overlap, and the hard margin has no solution then. The soft margin gives each row a slack e_i, the amount by which it may cross its margin line, and charges C for every unit of slack. A small C buys a wide margin with many rows inside it. A large C buys a narrow margin with few.

The same problem has a second form, the dual, with one weight alpha_i per row. The solution sets alpha_i = 0 for every row outside the margin. The rows with alpha_i above zero are the support vectors, and the prediction is a sum over them alone. Remove any other row and the fitted model is unchanged.

The kernel is where the line becomes a curve. Replacing the dot product with another kernel draws the boundary in a space of many more dimensions, and in the original two inputs that boundary is a curve. The RBF kernel has the second setting you will tune, gamma, which sets how far the influence of one row reaches. A large gamma lets every row bend the boundary around itself.

Regression turns the margin around. Support vector regression draws a tube of half width epsilon around the prediction. An error inside the tube costs nothing, and a row outside it pays C for every unit of distance beyond the tube. The rows on or outside the tube are the support vectors.
