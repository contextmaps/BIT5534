Section 1 of 5
INTRODUCTION
📋 Note for Students

Since week 2 you have fitted eight models: multiple regression and logistic regression, regression trees and decision trees, and on Tuesday and the week before, neural networks and support vector machines. Only the last two came with a validation column. Today all four tool families share one panel, so every model can be fitted and judged on the same rows.

A shared column makes a new move possible. The predictions of four models become the inputs of a fifth, which is called stacking.

Every tool you have used since week 2 now has the same panel. Choose the target and say whether it is a number or a category, choose the inputs, then make a validation column or pick one the file already has. Multiple regression and logistic regression now live in one tool, and the tree tool now holds rows back.

Each tool can save three things. A category target also has a positive class, the level whose probability the tool reports. It starts on the less frequent level, which is High in the diabetes file.

Stacking fits four base models on the inputs, saves each model's predictions as a new column, and fits one more model on those columns alone. The last model is the meta-model. It learns how much each base model deserves to be believed.

With a multiple regression as the meta-model, the stacked prediction is a weighted sum of the four predictions. Each coefficient is the weight the meta-model gives one base model, and its logworth says how sure the fit is that the weight is not zero.

For a category target the saved column is a probability. Each base model writes the probability of High for every row, and the meta-model is fitted on four probabilities. A logistic regression meta-model gives a weight to each one on the log odds scale.

The saved values have to come from models that did not see the row. A network fitted on a row predicts that row far better than it predicts a new one, and a meta-model fitted on those values learns to trust the network for the wrong reason. With a k fold column, each row's saved value comes from the fold model that left the row out. A test row was left out by every fold model, so it takes their average.

  • The meta-model on a number target is a multiple regression. What would a coefficient near zero on NN pred Y say about the network?
