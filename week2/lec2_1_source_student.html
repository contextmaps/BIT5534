Learning Objectives

  1. Distinguish the true line that generates data from the fitted line estimated out of one sample.
  2. Explain why a regression slope is a statistic, and describe the distribution it follows.

📋 Note for Students

Last week you produced a distribution for the sample mean and checked it against a variance you derived by hand. Today the same idea moves to a slope.

A regression coefficient is a statistic. It is computed from a sample, so it has a distribution, and every standard error and p-value a tool prints is a statement about that distribution. You will see that distribution before you see any regression output, which is the opposite of the usual order and the reason the output will make sense.

Section 1 of 5
INTRODUCTION

Those two numbers came out of fifty riders. The slope says one more minute of waiting is worth about 2.7 more cents, and the intercept says a rider who waits no time at all is worth about 6.9 cents.

Both are wrong. The process that made this data runs on an intercept of 5 and a slope of 3, and this sample missed both. Nothing in the picture says so.

A regression slope is computed from a sample, which makes it a statistic, which means it has a distribution. The whole lecture sits in that one sentence, and everything below is a picture of it.

Suppose the world really does run on Y = 5 + 3X + noise. Draw a sample, fit a line, and write down the slope. Do it again with a fresh sample and the slope comes out different. Do it a thousand times and the thousand slopes have a shape, which is what your instructor is about to put on screen.

Class material
The simulation your instructor is running
Write a single Python script named regression_sampling.py that I will run by
double-clicking. It takes no command-line arguments and prints nothing to the
console. Everything appears in one window that opens and stays open until I close
it, and that window redraws in place. It never opens a second window.

RUN

Startup check. Put every third-party import inside a try block. If any import
fails, use only Python's standard library to open a small window that names the
module that is missing, shows the full path of the interpreter running the script
from sys.executable, and gives a pip install command built from that same path, so
the install reaches the interpreter that will actually run the script. The script
must never close without showing me something.

Before you write any code, list every library the script needs that does not ship
with Python, and give me the exact command to install them.

INPUT

No data files. The script generates everything.

Constants, defined once at the top with these names and values:

    BETA0 = 5.0                    true intercept
    BETA1 = 3.0                    true slope
    SIGMA = 5.0                    standard deviation of the noise
    X_LOW, X_HIGH = 0.0, 10.0      X is uniform on this interval
    N_POP = 10000                  size of the population
    N_REPS = 1000                  samples drawn per run

Controls. Two, and no others. Place a numeric input field at the top of the window
labeled "Sample size (n)", pre-filled with 25, and a button labeled "Resample"
beside it. Pressing Resample, or pressing Enter inside the field, reads the field
and performs one full run.

Validation. Read the field as a real number, truncate it toward zero to an integer,
and require the result to be at least 1 and at most 10000. So 25.9 becomes 25 and
is accepted, while 0.5 becomes 0 and is rejected. If the field holds anything else,
anything non-numeric, or a value outside that range, show a short message in the
window and leave the previous display unchanged. Nothing recomputes and no panel
is cleared.

METHOD

Population. At startup, and again at the beginning of every run, build a fresh
population of N_POP pairs:

    draw N_POP values of X uniformly on [X_LOW, X_HIGH]
    Y = BETA0 + BETA1 * X + normal noise with standard deviation SIGMA

Samples. From that one population, repeat N_REPS times at the current sample size n:

    draw n rows at random with replacement
    fit a straight line by ordinary least squares on those rows:
        b1 = sum((x - mean(x)) * (y - mean(y))) / sum((x - mean(x))**2)
        b0 = mean(y) - b1 * mean(x)
    store b1 and b0

Every repetition draws from the same population, and the population itself is
rebuilt only when a new run begins. Keep the b1 and b0 from the first of the
N_REPS repetitions separately. That pair is "the first sample" and it is marked on
the two bottom panels.

Numbers. For each of the four distributions displayed, compute the mean and the
variance. For b1 and b0 also compute the empirical standard error, which is the
standard deviation across the N_REPS values, and the theoretical standard error:

    Var(X) = (X_HIGH - X_LOW)**2 / 12
    mean(X) = (X_LOW + X_HIGH) / 2
    SE(b1) = SIGMA / sqrt(n * Var(X))
    SE(b0) = SIGMA * sqrt(1/n + mean(X)**2 / (n * Var(X)))

OUTPUT

One window holding a two-by-two grid of histograms with the controls above it, and
a heading across the top reading the model and the current sample size, for example
"Y = 5 + 3X + noise, 1000 samples of n = 25".

Top left. The N_POP population values of X. Title "Population of X, wait at the
stop, minutes".

Top right. The N_POP population values of Y. Title "Population of Y, ad revenue,
cents".

Bottom left. The N_REPS values of b1. Title "1000 estimates of the slope b1". It
carries a vertical line at BETA1 in a colour different from the bars, and a red dot
sitting on the horizontal axis at the first sample's b1.

Bottom right. The N_REPS values of b0, with the vertical line at BETA0 and a red
dot on the horizontal axis at the first sample's b0. Title "1000 estimates of the
intercept b0".

The red dots. Filled red circles, large enough to read from the back of a
classroom, centred on the axis line itself and drawn on top of everything else so
no bar hides them. Each is labeled with its value. They appear only on the two
bottom panels, and they move to the new first sample on every run.

Numbers below the panels. Under each of the four panels, on its own line beneath
the horizontal axis, print the mean and the variance of what that panel shows, each
labeled and given to four decimal places. Under the two bottom panels add a second
line with the empirical standard error and the theoretical standard error, also
labeled and to four decimal places, so I can hold the tool against the formula.

Fixed axes. The horizontal axis limits of the two bottom panels are fixed and do
not change when the sample size changes. Use 0.5 to 6.0 for b1 and -15 to 25 for
b0. This is the single most important line in the specification. If those axes
rescale, the two histograms look identical at every sample size and the whole point
of the sample size field is lost. At larger n the bottom panels must visibly narrow
inside axes that stay put.

No y-axis tick labels on any panel. Around 45 histogram bins per panel.

GUARDS

The startup import check described under RUN, the input validation described under
INPUT, and one more: if a drawn sample happens to give a zero denominator in the
slope formula, discard that repetition and draw another, rather than raising.
Download regression_sampling.py
Needs numpy and matplotlib. Type a sample size, press Resample, and watch the two bottom panels narrow while the axes stay put.

The two panels along the top show the raw data, and the top-right one is visibly not normal. The two panels below show the estimates, and both are clean bells.

The data are not normal and the estimators are. Last week's central limit theorem has arrived somewhere you would not expect it.

double-clicking. No command-line arguments, nothing printed to a console. Use
pandas, statsmodels and matplotlib. Before writing any code, list the libraries I

INPUT

Open a file dialog offering .xlsx, .xls and .csv, and read the first sheet. If I
cancel, close quietly. The first row holds column names, the first column is the
response, and every other column is a predictor. Nothing is named in the script, so
the tool runs on any file of that shape.

Before fitting, check the data and stop with a message if any check fails: at least
two columns, every column numeric, at least one more row than the number of
predictors plus one, and no predictor that never changes. Drop any row with a
missing value and report how many you dropped.

METHOD

Fit ordinary least squares of the first column on all the others with an intercept,
using statsmodels, on the raw scale with no standardization and no variable
selection.

For each predictor compute the variance inflation factor. Include the intercept
column in the matrix you compute it from, because leaving it out silently inflates
every VIF.

For each predictor compute logworth, which is -log10 of its p-value. A p-value of
0.05 gives 1.30103. Cap logworth at 16 so an underflow cannot produce infinity.

OUTPUT

Write everything into a folder created beside the input file, named after it with
"_outputs" on the end.

with its logworth to two decimals just past the end of the bar. A vertical
reference line at 1.30103 labeled "p = 0.05". Leave room on the right so no label
is clipped.

residuals.png. Two panels sharing a vertical scale, each with a horizontal line at

Section 4 of 5
DISCUSSION

Two predictors in that table fail, and they fail in ways that are not the same thing. Students conflate them for years, so it is worth separating them once, out loud, while the output is on screen.

WkLoad has a p-value of 0.5501, which is weak evidence. It does not say workload is unrelated to sales. It says this sample cannot tell workload's effect apart from zero.

Accts has a VIF of 5.43, which is confused evidence. Other predictors carry much of the same information, so the estimate for Accts is unstable, and it would move a long way if the data changed slightly.
